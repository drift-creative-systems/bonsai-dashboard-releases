# Bonsai Dashboard releases

Installers and the update feed for **Bonsai Dashboard**, a Windows desktop dashboard by The Bonsai Digital Collective.

**[Download the latest version](https://github.com/drift-creative-systems/bonsai-dashboard-releases/releases/latest)**: run `Bonsai-Dashboard-Setup-x.x.x.exe`. Once installed, the app updates itself.

The source code is private. This repo only holds release files, so please don't open pull requests here.
